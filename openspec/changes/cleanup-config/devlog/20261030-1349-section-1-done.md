# Section 1 done: robustness fixes and module layout

<!-- Section: 1 · Tasks: 1.1–1.6 · Base: a7e4463 -->

New layout: `lua/config/{options,lazy}.lua`, `lua/lsp/{servers,keymaps}.lua`. `init.lua` calls keymap modules directly, with no `type()` guards and no `print`s. LSP modules require no plugins at load time. Mason is set up once (via `config = true`). The duplicate cmp `<Tab>`, the duplicate `<leader>fa` and the `regular.lua` duplicates are removed. `clipboard` is set in options for standalone mode only. `completeopt` is now owned by cmp.

Decision: **added `.gitattributes` (`*.lua text eol=lf`)**. Baseline `FORMAT_EXIT:1` came from `core.autocrlf=true` checking Lua out as CRLF while StyLua expects LF. The alternative was `line_endings = "Windows"` in `stylua.toml`. Rejected: LF in the repo is portable, and it keeps stylua and the gate in agreement. Files were renormalised in this commit.
