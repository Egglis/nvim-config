Gotchas:
- **WSL `$SHELL` is still `/bin/bash`**: the login shell becomes zsh in 4.2, so "shell is zsh" is only
  checked then (and in the 4.3 human check).
- **`wsl -- ./gates.sh` without `bash -l`** has no `~/.local/bin` on PATH → `FORMAT_EXIT:127`,
  `VALIDATE_EXIT:1`. Always run WSL gates through `bash -l <script>` until `.zshrc` (§3) sets PATH.
- **The clipboard provider's copy is async**: a test that `setreg`s and reads `win32yank.exe -o` straight
  away can see the old value; `vim.wait(500)` first.
- **`wslpath -w` converts nonexistent paths too** (exit 0), so the launcher's `|| exit 1` rarely fires; a
  bad file path just reaches explorer.exe. Left as is (spec only covers URLs).
- Headless probes that modify a buffer must end with `+qa!`, otherwise Neovim hangs on E37.
