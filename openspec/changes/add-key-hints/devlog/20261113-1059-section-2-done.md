hardtime decisions:
- `hardtime.setup()` applies its options on a 500 ms timer. Loading via `<leader>uh` then calling `enable()`
  straight away would use the plugin defaults (mouse off). So `config` merges our opts into
  `hardtime.config.config` first, passes `enabled = false`, and calls `enable()` itself when the state is on.
- `disabled_filetypes` adds `snacks_.*` (pickers, explorer, terminals, lazygit, dashboard) and `opencode.*`;
  terminals are also skipped by hardtime's own `buftype == "terminal"` check. `disable_mouse = false`.
- Otherwise defaults: 4th `hjkl` within 1 s blocked, arrow keys disabled (also in insert mode), hints on.
