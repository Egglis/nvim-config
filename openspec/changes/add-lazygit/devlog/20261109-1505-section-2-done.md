  callback runs with no error: `gs` git_status 1 item, `gl` git_log 71, `gf` git_log_file 9, `gb`
  git_branches 1, `gB` opens no picker (float); gitbrowse with a fake `open` gave
  `https://github.com/Egglis/nvim-config/blob/master/lua/plugins/snacks.lua#L1-L1`. `<leader>fg` is still
  `[F]ind [G]it changes`.

  compares the error to `"__ignore__"`, but the message carries a `file:line:` prefix, so it is
  re-raised. Fixed in our mapping: if `Snacks.git.get_root()` finds nothing, notify "Not in a git repo"
  and return. Re-tested: `NOTIFY lvl=3 "Not in a git repo"`, `ok=true`.
