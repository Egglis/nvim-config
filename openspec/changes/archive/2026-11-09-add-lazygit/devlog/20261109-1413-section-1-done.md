Gotchas for later sessions:
- Headless Neovim that opens a snacks terminal (lazygit, or any `cmd`) does **not** exit on `qall!`, and
  a `+lua` error leaves it hanging too. Run such checks with `Start-Process … -PassThru`, write results
  to a file, and kill the process after `WaitForExit(…)`. Clean up stray `nvim --headless`/`lazygit`
  afterwards; the user's own `nvim` sessions are running, so don't kill those.
- There is a stale 2025 swap file for `init.lua` in `nvim-data\swap`; it isn't ours, so leave it. Pass
  `-n` and a temp file to headless runs, not `init.lua`.
