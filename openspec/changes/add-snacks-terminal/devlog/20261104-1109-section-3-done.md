# Section 3 done: Ctrl+t toggle

<!-- Section: 3 · Tasks: 3.1–3.2 · Base: 36cfa29 -->

The user asked how to close the terminal, then said double `<Esc>` is annoying. Options offered: Ctrl+t
toggle, single Esc, Ctrl+h/j/k/l, Ctrl+Space/Alt. **User chose Ctrl+t.** This reverses the old design
decision 3. design.md, the terminal spec (new requirement "One-key toggle from terminal mode") and
tasks.md were updated (new §3; human verification is now §4).

`toggle_terminal()` in `snacks.lua`: with no count and the current buffer a snacks terminal (via
`vim.b.snacks_terminal`), hide the matching `Snacks.terminal.list()` entry; otherwise `focus()`. Used by
`<leader>tt` (n) and `<C-t>` (n, t). Side fix: `<leader>tt` in terminal 2 now hides 2 instead of jumping
to terminal 1. Trade-off: it replaces Vim's normal-mode `<C-t>` (tag pop); this is documented.

How to close a terminal for good (told to the user): type `exit` (auto-close on exit code 0), or `:bd!`.

Not checked headless (the user tests by hand).
